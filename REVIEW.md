Вариант 1. Ошибка в условии
Область: Синтаксис (SyntaxError)

Проблема:
При запуске этого кода Python выдаст SyntaxError: expected ':'. Интерпретатор не понимает, где заканчивается условие if, потому что пропущен обязательный синтаксический элемент.
Решение:
В языке Python после условий (if, elif, else), циклов (for, while) и объявления функций/классов всегда нужно ставить двоеточие :.

Вариант 2. Неправильные типы данных
Область: Типы данных (TypeError)

Проблема:
Код выдаст TypeError: can only concatenate str (not "int") to str. Python строго относится к типам данных: он не умеет автоматически складывать (конкатенировать) строку (str) и число (int). Кроме того, математическое вычитание price - discount внутри строкового сложения вызовет путаницу в порядке выполнения операций.
Решение:
Нужно либо явно преобразовать числа в строки с помощью функции str(), либо (что является более современным и правильным подходом) использовать f-строки (форматированные строки), которые сами подставляют значения.

Вариант 3. Скрытая логическая ошибка
Область: Логика алгоритма (Logic Error)

Проблема:
Этот код не выдаст никакой ошибки и успешно выполнится. Но он работает неверно! На экран выведется 0, хотя в списке нет ни одного положительного числа.
Проблема в том, что мы задали начальное значение max_temp = 0. Поскольку все температуры в списке отрицательные, условие temp > 0 никогда не сработает, и переменная не обновится.
Решение:
Чтобы найти максимум в списке чисел (особенно если они могут быть отрицательными), нужно инициализировать переменную первым элементом списка или использовать встроенную функцию max().

Вариант 4. Опечатка в имени переменной
Область: Имена переменных (NameError)

Проблема:
Код выдаст NameError: name 'bonys' is not defined. Python не нашел переменную с именем bonys, потому что мы создали её с именем bonus (без 's' на конце). Python чувствителен к регистру и опечаткам.
Решение:
Внимательно проверить имена переменных. Убедиться, что переменная объявлена до её использования и написана везде одинаково.
